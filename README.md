# AI Search Algorithm Implementations

A Python learning repository for exploring classical Artificial Intelligence search strategies and graph-based problem solving.

The examples use graph and state-space search to demonstrate how different algorithms expand nodes, select paths, and balance completeness, optimality, and search cost.

## Algorithms and notebooks

The repository currently includes notebooks for:

- Breadth-First Search (BFS) — `bfs.ipynb`
- Depth-First Search (DFS) — `dfs.ipynb`
- Depth-Limited Search (DLS) — `dls.ipynb`
- Iterative Deepening Search (IDS) — `ids.ipynb`
- Uniform-Cost Search (UCS) — `ucs.ipynb`
- Greedy Best-First Search — `greedy.ipynb`
- A* Search — `astar.ipynb`
- Bidirectional Search — `bds.ipynb`

The repository also includes `graph.py` for graph-related code and `documents.ipynb` for supporting study material.

## Technology

- Python 3
- Jupyter Notebook
- Git and GitHub

## Getting started

### 1. Clone the repository

```bash
git clone https://github.com/kura458/AI-Search-Algorithm-Implementations.git
cd AI-Search-Algorithm-Implementations
```

### 2. (Optional) Create a virtual environment

On Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Install Jupyter

```bash
python -m pip install notebook
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

Open a notebook and run its cells in order. Review the graph representation and inputs before comparing the algorithms' outputs.

## Learning objectives

- Understand graph traversal and state-space search.
- Compare uninformed and informed search strategies.
- Explore heuristic-guided pathfinding.
- Practice implementing and tracing search algorithms.
- Analyze how algorithm choice affects node expansion and path selection.
